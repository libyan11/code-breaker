# Code Breaker

## ▶ [Play the game](https://libyan11.github.io/code-breaker/)

https://libyan11.github.io/code-breaker/

Crack the secret colour code from the clues, in your browser on phone or computer. A new daily code for everyone each day (keep your streak and share your result), or race friends and computer players online. Works offline after the first visit. Part of [Game Night](https://libyan11.github.io/).

**Race your friends:** one person taps *Create a room* and shares the 4-letter code or link. Everyone cracks the same code; fewest tries wins.

**Rules**
- Tap colours to fill a row, then tap Check.
- ● = a right colour in the right spot. ○ = a right colour in the wrong spot.
- Easy: 4 pegs, 6 colours, no repeats. Normal: repeats allowed. Hard: 5 pegs, 8 colours, 12 tries.
- In a room: fastest cracker gets 3 points, then 2, then 1.
